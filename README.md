# F&K PRO — Facturation automatique

Application web (HTML/CSS/JS, sans serveur) pour créer, enregistrer et imprimer les factures proforma, factures et devis de **F&K PRO**.

- Numérotation automatique (`0011/FNK/2026`, …)
- Calcul automatique : Nombre × Qté × Prix unitaire, Total HT, TVA 18 %, Total TTC
- Montant en toutes lettres en français
- Historique des factures (enregistré dans le navigateur), duplication, recherche
- Impression / export PDF au format A4 (bouton « Imprimer / PDF »)
- Cachet / signature : à charger dans « Paramètres de l'entreprise » (conservé uniquement sur l'appareil, jamais publié)

Les données restent dans le navigateur utilisé : chaque ordinateur a son propre historique.
